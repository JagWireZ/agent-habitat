# Default egress allowlist -- Agent Habitat, Phase 5.
#
# One hostname pattern per line. Blank lines and lines starting with "#"
# are ignored. A bare hostname (e.g. `pypi.org`) matches that exact host
# only. A pattern prefixed `*.` (e.g. `*.githubusercontent.com`) matches
# any subdomain of the suffix, but never the bare suffix itself -- list
# the bare host separately if it must also be reachable directly.
# Matching is case-insensitive and never IP-based (`docs/decisions/
# 0004-networking-layer.md`): the destination inspected is the SNI
# hostname a guest's TLS ClientHello names at connection setup, so a
# direct-IP connection carries no hostname to match and is denied by
# construction, never allowed via some IP-address fallback.
#
# This list ships with Agent Habitat itself and is baked into the binary
# (see `egress_allowlist.rs`'s `include_str!`) -- it is not read from disk
# at runtime. A project's own additions come from that project's
# checked-in config file instead (`habitat_policy::config`'s
# `egress_allowlist_additions`), and are always additive: nothing here
# can be removed or overridden per-project (same rule as
# `policy/blocklist.txt`).
#
# v1 platform target is AlmaLinux only (`docs/decisions/
# 0001-host-os-layer.md`) -- package-registry entries below are scoped to
# that; Fedora/Ubuntu registry mirrors are added when those roadmap
# stages actually start, not built ahead.
